NACHI

Mar 2023 – Feb 2025 · Industrial Grant · 마지막 업데이트: 2026-08-22

Project 개요

산업 현장에서 flexible printed circuit(FPC)을 connector에 자동으로 삽입하기 위한 learning-based robotic manipulation 프로젝트입니다. 쉽게 변형되는 FPC의 형상과 connector 위치를 vision으로 인식하고, 인식 결과를 실제 robot manipulation으로 연결하는 시스템을 개발했습니다.

주요 기여

  • Flexible FPC와 connector를 검출하기 위한 vision-based framework 설계
  • 인식 결과를 robot manipulation pipeline과 통합
  • 개발한 robotic system을 실제 생산 시설에 배포

Technical Challenges

FPC는 rigid object와 달리 grasp와 motion 과정에서 형태가 변하기 때문에 동일한 위치와 자세를 반복해서 가정하기 어렵습니다. 따라서 visual perception을 통해 FPC와 connector의 상태를 파악하고, 실제 robot system에서 사용할 수 있는 형태로 전달하는 것이 중요합니다.

Skills

Computer Vision · Flexible Object Manipulation · Robot Deployment · Python · ROS · System Integration
