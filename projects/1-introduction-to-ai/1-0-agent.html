1-0. Agent Overview

마지막 업데이트: 2025-10-03

개요

인공지능에서 에이전트(agent)라는 말은 조금 넓은 의미를 가집니다.
가장 많이 쓰이는 정의는 다음과 같습니다.

“에이전트란 환경으로부터 입력(지각, percept)을 받아서, 그에 따라 행동(action)을 결정하는 어떤 것.”
또는 수학적으로는, “지각의 역사(percept history)를 행동으로 대응시키는 함수”라고도 부릅니다.

중요한 점은, 여기서 에이전트는 특정한 형태(로봇, 사람 등)에 묶여 있지 않다는 것입니다.
즉, 에이전트는

  • 물리적인 로봇(자율주행차, 드론, 조작 로봇)일 수도 있고,
  • 웹 브라우저 안에서 자동으로 클릭하고 폼을 채우는 소프트웨어 프로그램일 수도 있고,
  • 심지어 “환경을 인식하고, 그에 맞게 행동하는” 인간 또는 인간 집단을 추상적으로 모델링한 것일 수도 있습니다.

즉, 에이전트는 ‘물리적 실체’의 이름이라기보다, “입력 → 내부 처리 → 출력(행동)” 구조를 가진 추상적인 개념입니다.
그래서 같은 이론으로 로봇, 소프트웨어, 사람 팀(team)까지 한꺼번에 다룰 수 있습니다.

예시

조금 더 감이 오도록, 서로 다른 종류의 에이전트 예시를 들어보겠습니다.

  • 물리적 로봇 에이전트
    카메라와 센서를 통해 주변을 관측하고, 바퀴나 팔을 움직여 물체를 집거나 이동하는 로봇.
    환경: 물리 세계 / 지각: 센서 값 / 행동: 모터 제어 신호
  • 소프트웨어 에이전트
    사용자의 메일과 캘린더를 읽고, 회의 시간을 제안하고, 자동으로 초대 메일을 보내는 일정 관리 봇.
    환경: 이메일·캘린더 서버 / 지각: 메일·일정 데이터 / 행동: 메일 전송, 일정 생성
  • 웹 브라우저 에이전트
    사용자가 “도쿄 3박 4일 여행 계획 짜줘”라고 하면, 웹을 검색하고, 항공권·숙소를 비교하고,
    브라우저에서 직접 버튼을 클릭하며 예약을 진행하는 시스템.
    환경: 웹 페이지 / 지각: HTML·텍스트 / 행동: 클릭, 입력, 폼 제출
  • 인간을 에이전트로 보는 시각
    고전적인 AI 이론에서는 인간도 하나의 에이전트로 볼 수 있습니다.
    눈·귀로 환경을 관찰하고, 뇌에서 판단을 내리고, 손·발로 행동을 선택한다는 관점에서,
    사람 역시 “지각 → 처리 → 행동” 구조를 가진 에이전트입니다.
  • 다중 에이전트 시스템(Multi-agent system)
    여러 로봇이 창고에서 물건을 동시에 옮기는 시스템처럼, 에이전트 여러 개가 서로 영향을 주고받는 경우도 있습니다.
    이때는 각 로봇이 하나의 에이전트가 되고, 전체 시스템은 여러 에이전트가 상호작용하는 환경이 됩니다.
