BRL

Aug 2024 – Present · Project Manager · 마지막 업데이트: 2026-08-22

Project 개요

초고령사회에서 고령 사용자가 teleoperated robot을 보다 쉽게 조작할 수 있도록 shared autonomy를 개발하는 정부 과제입니다. 사용자가 모든 low-level motion을 직접 명령하는 대신, 로봇이 상황을 이해하고 high-level task를 계획하며 필요한 경우 사용자에게 feedback을 요청하는 구조를 목표로 합니다.

주요 기여

  • High-level robotic task를 생성하는 LLM-based task planner 개발
  • 생성된 task plan을 Behavior Tree로 변환하여 robot execution과 연결
  • Perception, motion, planning을 연결하는 end-to-end framework 개발
  • UI에서 전달되는 corrective feedback을 task planner에 반영하여 실행 중 plan을 수정하는 구조 개발

System Pipeline

시스템은 환경과 사용자 명령을 입력받아 task plan을 생성하고, 이를 Behavior Tree를 통해 실행 가능한 robot behavior로 변환합니다. 실행 과정에서 문제가 발생하거나 사용자의 의도와 다른 결과가 예상되면 UI feedback을 받아 plan을 보완합니다.

Knowledge Base는 domain knowledge와 현재까지 관측된 정보를 관리합니다. Planning Manager는 현재 knowledge state를 바탕으로 action과 motion을 결정하고, 정보가 충분하지 않으면 Feedback Manager가 사용자가 이해하기 쉬운 query를 생성합니다. 사용자의 응답은 belief와 knowledge state에 반영되어 이후 계획을 수정하는 데 사용됩니다.

Skills
